# معماری نهایی پروژه

## رویکرد: EA-Based (بدون نیاز به پسورد کاربر)

### لایه‌ها

```
┌─────────────────────────────────────────┐
│  📱 Panel (HTML/JS - ساده)              │
│     فایل نتایج EA را می‌خواند           │
│     دکمه Refresh دارد                   │
├─────────────────────────────────────────┤
│  📄 فایل نتایج (JSON/CSV)              │
│     توسط EA نوشته می‌شود                │
│     توسط Panel خوانده می‌شود            │
├─────────────────────────────────────────┤
│  🤖 Expert Advisor (.mq5)              │
│     داخل MT5 اجرا می‌شود               │
│     استراتژی را پیاده می‌کند             │
│     معاملات را مدیریت می‌کند            │
│     نتایج را در فایل ذخیره می‌کند       │
├─────────────────────────────────────────┤
│  📊 MetaTrader 5                        │
│     حساب کاربر اینجا متصل است          │
│     رمز فقط در MT5 وارد می‌شود         │
└─────────────────────────────────────────┘
```

### جریان داده

1. کاربر MT5 را باز می‌کند
2. EA را روی نماد و تایم‌فریم اجرا می‌کند
3. EA استراتژی را اجرا می‌کند
4. EA معاملات را مدیریت می‌کند
5. EA نتایج را در فایل می‌نویسد
6. Panel فایل را می‌خواند و نمایش می‌دهد
7. کاربر با دکمه Refresh به‌روز می‌کند

### فایل‌های EA

- `Strategy_EA.mq5` - Expert Advisor اصلی
- در پوشه `MQL5/Experts/` MT5 نصب می‌شود

### فایل‌های نتایج

- `trading_results.json` - نتایج معاملات
- `strategy_signals.json` - سیگنال‌های استراتژی

### مزایا

- ✅ هیچ پسوردی ذخیره نمی‌شود
- ✅ کاربر کنترل کامل دارد
- ✅ امن و قابل اعتماد
- ✅ ساده و قابل فهم
